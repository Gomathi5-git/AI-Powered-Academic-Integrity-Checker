1. OBJECTIVE
------------------------------------------------------------

An automated retraining pipeline was implemented to retrain
the plagiarism detection model using the latest available
training data.

trained model meets minimum performance requirements before
it replaces the currently deployed model.

10. VALIDATION GATE BEHAVIOUR
------------------------------------------------------------

The validation gate prevents a poorly performing model from
being deployed.

If the new model fails either the minimum accuracy or minimum
F1-score requirement, the pipeline rejects the model and the
existing deployed model remains unchanged.

This provides a basic safety mechanism for automated model
retraining.


11. LIMITATIONS
------------------------------------------------------------

The current training dataset contains only 12 samples.

Therefore, the reported performance should not be considered
representative of production performance.

The validation gates currently use fixed thresholds of 80%
for accuracy and F1 score.

A production system would require a larger and continuously
updated dataset together with stronger validation procedures.
