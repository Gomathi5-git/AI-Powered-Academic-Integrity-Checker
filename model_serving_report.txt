==================================================
MODEL SERVING LAYER REPORT
==================================================

1. SERVING ARCHITECTURE & DATA FLOW
-----------------------------------
- Framework           : FastAPI (Python REST API service)
- Web Server          : Uvicorn ASGI Server
- Data Serialization  : Pydantic v2 schemas for request and response validation
- Preprocessing Pipeline: TF-IDF Feature Extraction (TfidfVectorizer loaded from tfidf_vectorizer.pkl)
- Machine Learning Model: Random Forest Classifier (loaded from random_forest_model.pkl / best_model.pkl)

Data Flow:
Client Request (JSON) -> Pydantic Validation -> TF-IDF Feature Extraction -> Random Forest Model -> Structured Prediction JSON

2. SELECTED MODEL & ARTIFACT DETAILS
------------------------------------
- Model Algorithm   : Random Forest Classifier (n_estimators=50, max_depth=None, random_state=42)
- Selection Basis   : Selected from Phase 2 Task 5 based on highest cross-validation Mean F1 Score (0.9333 ± 0.1333).
- Model Artifact    : random_forest_model.pkl
- Vectorizer Artifact: tfidf_vectorizer.pkl (Vocabulary size: 35 features)
- Supported Classes : ["original", "plagiarized"]

3. ENDPOINTS CREATED
--------------------
1. GET /health
   - Description: Service status check and loaded model metadata.
   - Status Code : 200 OK (503 if artifacts fail to load).
   - Response    : {"status": "healthy", "model": "Random Forest"}

2. POST /predict
   - Description: Accepts text submission, computes TF-IDF features, predicts plagiarism class, boolean flag, and confidence.
   - Status Code : 200 OK (Inference Success) / 422 Unprocessable Entity (Validation Error)
   - Example Response:
     {
         "prediction": "plagiarized",
         "is_plagiarized": true,
         "confidence": 0.7895
     }

4. INPUT VALIDATION RULES
-------------------------
- Text must be a non-null string.
- Text must not be empty ("").
- Text must not consist solely of whitespace ("   ").
- Text length must not exceed 10,000 characters.
- Invalid requests return HTTP 422 Unprocessable Entity with detailed JSON error messages.

5. TESTING RESULTS
------------------
- Test Suite File : test_api.py (FastAPI TestClient + pytest)
- Tests Executed  : 8 tests
- Test Pass Rate  : 100% (8 passed, 0 failed)
- Evaluated Tests :

  2. POST /predict valid original submission -> HTTP 200
  3. POST /predict valid plagiarized submission -> HTTP 200
  4. POST /predict empty text -> HTTP 422
  5. POST /predict whitespace text -> HTTP 422
  6. POST /predict missing text field -> HTTP 422
  7. POST /predict invalid data type -> HTTP 422
  8. POST /predict text length > 10,000 chars -> HTTP 422

6. SMALL DATASET LIMITATIONS & DISCLAIMER
-----------------------------------------
- Serving functionality (API request handling, schema validation, HTTP routing) is fully operational.
- Model performance (accuracy, precision, recall) remains preliminary because the training dataset contains only a small number of prototype samples (12 training samples, 2 test samples).
- High model confidence on tiny test samples does NOT indicate production-level plagiarism detection accuracy.
